Resonance — Reliable Google Drive EPUB Discovery & Live Batch Import Progress.

What's in this build:
• Catches missing Google Drive EPUBs inside subfolders: normalizes Android SAF subfolder URIs and peeks 256-byte file headers when Drive reports EPUBs as application/octet-stream or application/zip
• Fixes stalled / colliding batch imports: defers on-device ONNX embedding until the entire batch finishes (preventing SQLite transaction contention & CPU thrashing) and writes local copies natively without JS base64 loops
• Adds a pinned Batch Import Progress Card with live progress bar, current book name, active stage (Downloading → Extracting chapters → Saving), running imported/skipped/failed counts, Stop button, and clear error details
• Adds a 45-second timeout per file so a stalled cloud file can never freeze an entire batch
