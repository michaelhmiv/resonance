Resonance — Personal Library Individual Files & Cloud Folder Import build.

What's in this build:
• Added individual & multi-file import ("Choose files") in Add to Your Library — pick one or more EPUB, PDF, DOCX, HTML, Markdown, or TXT books directly from your phone, Google Drive, iCloud Drive, or Downloads (single picks jump straight to metadata review; multi-picks stage for 1-tap batch import)
• Fixed Google Drive / cloud folder import crash by migrating Personal Library folder scanning and file reading off expo-file-system/legacy SAF to modern expo-file-system v56 APIs
• Added MIME-type & magic-byte format detection, clean Google Drive folder labels, and metadata-backed title resolution for opaque cloud URIs
• Everything remains 100% local after import — files are copied, extracted, and embedded on-device
