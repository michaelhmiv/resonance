Resonance — Audited Clean Corpus & Browsable Library Catalog build.

What's in this build:
• Deep corpus audit & scrubbing across the entire Church Library: removed 100% of Google Books watermarks/preambles, raw Archive.org YAML headers, Project Gutenberg/Transcriber footers, library loan slips, URLs, Victorian publisher catalogs, back-of-book indexes, OCR cover noise, TOC-only stubs, severely corrupted scans, and duplicate editions (72 clean, audited Church classics + WEB Bible)
• Stronger on-device document boilerplate scrubbing for Personal Library imports (EPUB, PDF, DOCX, HTML, Markdown, TXT)
• Core-only initial download prompt (Voyage-4-Nano 512d INT8 + Qwen3-Reranker-0.6B INT8 + ~4 MB Bible vectors = ~998 MB)
• Browsable Library Catalog (Word → Library → Browse Catalog, and Settings → Browse Library Catalog) to cherry-pick individual books (50 KB–2 MB) or whole collections with fast batched SQLite installation
• Living Concordance Patterns tab, Study Bookshelf, and gold open-book app icon on cream
