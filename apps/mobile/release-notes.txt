Resonance — Responsive Add to Library & Catalog Sheets (Swipe-Down + Non-Blocking Scan).

What's in this build:
• Fixes non-responsive "Add to Your Library" sheet: replaces synchronous Google Drive/SAF header peeking and tight folder-scan loops with async native reads + cooperative UI frame yields so the JS thread never locks up
• Adds interactive swipe-down-to-dismiss on the handle and header bar, tap-outside backdrop dismissal, and larger circular Close (×) buttons across Add to Library, Library Catalog, and Offline Engine sheets
• Unmounts closed sheets cleanly, uses granular store selectors, and paginates large discovered book lists (40 at a time) so opening, scrolling, and closing stay instant even with hundreds of cloud books
• Closing Add to Library stops any in-progress folder scan immediately while keeping active book imports, catalog downloads, and embeddings running in the background
